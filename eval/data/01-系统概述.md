# 系统概述

本系统是一个纠正式检索增强生成（Corrective RAG）系统，基于 LangGraph 构建，核心作用是从本地文档中检索信息并生成回答。与普通 RAG 相比，它增加了文档相关性评分、查询改写和网络搜索兜底，避免直接使用不相关的内容生成答案。

输入方式有三种，可以多选合并使用：URL（多行文本框，每行一个链接）、本地路径/文件夹（递归扫描所有支持格式）、文件上传（支持多选，单次上限可配置，默认 50 个，范围 1 到 500）。

所有 API 配置都从项目根目录的 .env 文件读取，包括大语言模型 API（默认 DeepSeek 官方接口）、向量模型配置、Tavily 搜索密钥、Qdrant Cloud 地址与密钥。

系统支持多知识库：所有知识库的数据存放在同一个 Qdrant 集合里，通过 kb 标签过滤区分；知识库名称记录在项目根目录的 knowledge_bases.json 注册表中，默认知识库不可删除。

入库采用边扫描边分批的方式（每批 20 条向量化后立即写入），带进度条；回答阶段也按工作流步骤显示进度条。

启动方式：先运行 uv sync 安装依赖，再运行 uv run streamlit run corrective_rag.py。
