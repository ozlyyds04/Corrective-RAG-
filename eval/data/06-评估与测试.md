# 评估与测试

项目带有 pytest 测试套件，共 31 个用例，覆盖文档加载器（UTF-8/GBK 回退、CSV、HTML、DOCX、文件夹递归）、纠错工作流路由（使用假 LLM 与假检索器）、Streamlit 界面冒烟测试。

评估脚本 evaluate.py 用 LLM-as-judge（默认 deepseek-v4-flash 裁判）对比基线 RAG（检索后直接生成）与纠错 RAG 的指标：检索精度 precision@k、命中率 hit_rate、忠实度 faithfulness、幻觉率（1 减 faithfulness）、答案正确性 correctness、回答相关性 answer_relevance，以及无支撑断言数。

评测问题集位于 eval/questions.json，示例语料位于 eval/data/；报告输出到 eval/reports/eval_latest.json。

已知局限：评测集规模较小，统计存在噪声；LLM 裁判存在稳定性问题；忠实度判分对内容丰富的回答偏严格。
